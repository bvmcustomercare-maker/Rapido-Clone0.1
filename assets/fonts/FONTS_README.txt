FONTS REQUIRED — DOWNLOAD FROM GOOGLE FONTS
============================================

This project uses the "Inter" typeface from Google Fonts.

Download URL: https://fonts.google.com/specimen/Inter

Required files (place in this folder):
  - Inter-Regular.ttf    (weight 400)
  - Inter-Medium.ttf     (weight 500)
  - Inter-SemiBold.ttf   (weight 600)
  - Inter-Bold.ttf       (weight 700)

After placing the files here, run:
  flutter pub get

Note: If you want to skip custom fonts for testing, change the
fontFamily value in app_theme.dart from 'Inter' to null to use
the system default font.
